GALERIA ONLINE - CARLOS VENTURA
Sobre o Projeto

A Galeria Online Carlos Ventura é uma aplicação web responsiva desenvolvida para apresentar, 
organizar e simular a comercialização de obras de arte de forma moderna e intuitiva.

O sistema permite visualizar obras disponíveis e vendidas, aplicar filtros dinâmicos, 
consultar preços em moedas internacionais e registrar pedidos simulados diretamente no navegador.

O projeto foi desenvolvido utilizando apenas tecnologias front-end, com foco em:

experiência do usuário
responsividade
acessibilidade
organização visual
manipulação dinâmica do DOM
consumo de API externa

Objetivo do Projeto

O objetivo do projeto é aplicar conceitos de desenvolvimento web moderno através da criação de uma galeria online funcional e interativa, 
simulando um ambiente real de apresentação e gerenciamento de obras artísticas.
